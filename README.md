# МастерДом — сайт строительной компании

Сайт компании по ремонту квартир и домов «под ключ» с онлайн-инструментами для клиентов: калькулятором стоимости ремонта, 3D-визуализацией и AI-консультантом.

**Контакт:** Александр — 8 916 143-78-79 (ежедневно 9:00–21:00)

## Структура сайта

| Адрес | Страница |
|---|---|
| `/` | Главная — лендинг компании: услуги, AI-дизайн, этапы работы, цены, контакты |
| `/calculator` | Онлайн-калькулятор ремонта с 3D-визуализацией и AI-чатом |
| `/project/:id` | Просмотр сохранённого проекта по ссылке (для клиента/подрядчика) |
| `/admin` | Админ-панель: цены, проекты |

## Возможности

### Главная страница
- Услуги: ремонт квартир и домов под ключ, косметический и капитальный ремонт, ванные, электрика и сантехника
- Раздел AI-дизайна с переходом в онлайн-инструменты
- Этапы работы, преимущества, тарифы
- Контакты: телефон, WhatsApp, Telegram, плавающая кнопка звонка на мобильных

### Калькулятор (вторичный инструмент)
- **3D-визуализация комнат** — интерактивный просмотр с вращением и масштабированием
- **Расчёт стоимости** — автоматический подсчёт по выбранным работам и площади
- **AI чат-помощник** — рекомендации по ремонту (готов к интеграции Claude API)
- **Экспорт в Excel** — детальная смета в формате .xlsx
- **Шаринг проектов** — ссылка на проект для подрядчика

## Технологии

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **3D**: Three.js
- **Backend**: Node.js + Express
- **Database**: SQLite (better-sqlite3)
- **Excel**: xlsx

## Установка

Требуется Node.js 16+.

```bash
git clone <repo-url>
cd Design-renovation-
npm install
npm start
```

Сервер запустится на `http://localhost:3000`.

## Конфигурация

Скопируйте `.env.example` в `.env` и заполните значения:

- `PORT` — порт сервера (по умолчанию 3000)
- `ADMIN_SESSION_SECRET` — секрет для сессий админки
- `ANTHROPIC_API_KEY` — ключ Claude API для AI-чата (опционально, без него работают mock-ответы)

## Админ-панель

Доступна по адресу `/admin` (пароль по умолчанию: `admin123` — смените после первого входа).

- Управление ценами на работы
- Просмотр всех проектов клиентов
- Смена пароля администратора

## API Endpoints

### Проекты
- `POST /api/projects` — создать проект
- `GET /api/projects/:shareId` — получить проект
- `PUT /api/projects/:shareId` — обновить проект

### Цены
- `GET /api/pricing` — активные цены
- `PUT /api/pricing/:id` — обновить цену (админ)
- `GET /api/admin/pricing` — все цены (админ)
- `POST /api/admin/pricing` — добавить услугу (админ)

### Прочее
- `GET /api/export/:shareId` — скачать смету Excel
- `POST /api/chat` — сообщение AI-чату
- `POST /api/admin/login` / `POST /api/admin/logout` — вход/выход
- `PUT /api/admin/password` — смена пароля
- `GET /api/admin/projects` — список проектов
